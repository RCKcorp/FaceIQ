# Roadmap vidéo FaceIQ

## Fait dans le MVP

- Analyse des images.
- Analyse des vidéos par extraction de frames.
- Extraction des visages.
- Score qualité.
- Export CSV.
- CLI avec paramètres utiles.

## Prochaines évolutions

- Interface graphique Windows.
- Rapport HTML avec aperçu des visages.
- Suppression intelligente des doublons vidéo.
- Regroupement des visages par personne.
- Export `.exe` avec PyInstaller.
